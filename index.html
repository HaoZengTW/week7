  • 現況問題：無已知設備先追問；一般 SOP 可直接查

固定快照，如何接到 Agent 測試？

  1. 複製固定 JSON（固定時間是歷史測試資料）。
  2. 老師另建測試工作流：Webhook GET → Edit Fields → Respond JSON。
  3. Edit Fields 的 JSON 模式放入快照；工具暫接這支測試 URL。
  4. 只測固定 FAN-02；各情境跑完，再還原老師的即時 API。
固定來源只在測試副本使用；Prompt 明示「此輪為歷史固定快照驗收」，不可當成現在的真實讀值。
